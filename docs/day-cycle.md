# 时间与光照边界

设备 Date 提供本地时间，Intl 显示时区，不请求城市或位置。environment.ts 将一天映射为美术时段，已有边界和连续性测试。

当前预渲染版始终保留用户确认的黄昏天空。时段通过 `1 + (env.backdrop - 1) * 0.15` 轻微调整全景亮度，不改变太阳位置、云层、窗内绘制的光照或真实天气。默认跟随当地时间；手动时段与加速播放只影响页面，点击「当地时间」恢复。

橱窗遮罩有 9 秒缓慢明暗呼吸；prefers-reduced-motion 关闭动画、过渡和加速演示。视觉验收固定黄昏 18:30。若后续需要完整白天与夜晚，应先制作并分别验收对应画面，不直接用强滤镜冲淡原稿。
