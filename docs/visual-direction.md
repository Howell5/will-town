# 视觉修订：实体山城街道

用户明确提出：视觉永远是第一位，否定初版悬空薄板和粗糙的重复建筑。功能验收不能替代视觉验收。

## 本轮参考

主参考仍为本仓库的 `references/town-concept.png`。通过 ego-lite 查看了 Square Enix 官方资料页和下列《八方旅人 II》实机截图。游戏图片只用于观察，不作为运行时素材，也不复制到公开仓库。

- [Square Enix 官方资料](https://press.na.square-enix.com/OCTOPATH-TRAVELER-II)：官方将 HD-2D 描述为像素艺术与 3DCG 的融合。
- [集市截图 141](https://www.rpgfan.com/wp-content/uploads/2022/09/Octopath-Traveler-II-Screenshot-141-1280x720.jpg)：连续铺装路面连接摊位、台阶和前景，明暗在可走街道上形成层次。
- [村镇截图 140](https://www.rpgfan.com/wp-content/uploads/2022/09/Octopath-Traveler-II-Screenshot-140-1280x720.jpg)：多层石墙、台阶、栏杆、屋檐与路面互相遮挡，没有悬浮展台的完整底边。

以上是对已查看画面的观察，不是对游戏内部实现的断言。

## 已改的结构

- 由薄平台改为厚重连续地基，增加逐层石块、支撑柱、栏杆压顶、十二级台阶和下层街道。地基延伸到画面下方，不暴露悬空底面。
- 墙面用有倒角的独立石块，门窗留实际凹槽；增加侧墙、墙角石、窗台、百叶窗、窗框和山墙细部。
- 屋顶用有截面厚度的弧形瓦片，分排铺设，并加入屋脊、檐口与错开的烟囱。
- 橱窗插画放在凹进去的玻璃格后方；门把手、遮雨棚、台阶、立式小黑板和灯具保留真实几何结构。
- 重做黄昏色调、冷色补光、近处暖光和克制的后期辉光；保留背景透明度，避免后期把天空遮黑。
- 重复石块和瓦片使用实例化渲染。像素材质只负责微观表面，轮廓和投影由几何结构提供。

## 当前限制

下层街道与台阶用于构图，当前可走范围仍是上层街道。建筑仍比原概念稿规整，植物密度和远近景衔接也未达到原稿；不把这一版称为最终美术定稿。运行检查与视觉结论见 `../design-qa.md`。

## 固定参考镜头与岸线校准

后续用户明确否定“视角差不多”，要求用原图作为构图硬约束。新增 `src/camera.ts`：桌面正交镜头俯角 14°、方位角 12°、无滚转；缩放按 1487 × 1058 画幅等比适配，桌面行走不再移动镜头。窄屏仍横向跟随角色。

参考定位点由图片手工观察确定，有像素测量误差。中店门槛约 (922,848)、前山墙顶点 (922,378)、右店门槛 (1200,882)、前山墙顶点 (1195,406)、角色脚下 (816,864)。当前投影对应 (921,846)、(921,384)、(1185,869)、(1185,403)、(809,857)。仅检验这些位置，不代表全部屋顶轮廓或整图相似度。

地面的法向量仍朝上，全部行走保持同一高度。前方岸线在平面中按 `z = 9.64 + 0.5 * (x - 0.7)` 延伸，厚地基按同一个多边形挤出，避免把路面旋转成坡道。屋顶纵深缩短、上层双窗改为单窗、底层加高。新前景树叶和远景为生成图片，交互建筑与地面仍是真实几何。
